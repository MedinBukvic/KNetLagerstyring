Velkommen til Lagerstyring

3 trin og du er kørende med rigtig team-sync via Supabase.

1 Opret et gratis Supabase-projekt

Gå til supabase.com/dashboard, log ind og klik "New project". Vælg en region tæt på dig (Frankfurt for Danmark) og vent ~2 min til projektet er klar.

2 Kør denne SQL i Supabase

Åbn SQL Editor i venstre menu på Supabase → "New query" → paste hele blokken → "Run". Det opretter tabeller, RLS-politikker, realtime og seeder 5 navne.

-- ===== TABLES =====
create table if not exists products (
  id uuid primary key default gen_random_uuid(),
  name text not null unique,
  stock integer not null default 0,
  low_threshold integer not null default 5,
  created_at timestamptz default now()
);

create table if not exists activities (
  id uuid primary key default gen_random_uuid(),
  timestamp timestamptz default now(),
  user_name text not null,
  product_id uuid,
  product_name text not null,
  delta integer not null default 0,
  type text not null check (type in ('adjust','count','create','delete')),
  note text
);

create table if not exists app_users (
  id uuid primary key default gen_random_uuid(),
  name text not null unique,
  created_at timestamptz default now()
);

-- ===== RLS (open policies — small-team usage) =====
alter table products enable row level security;
alter table activities enable row level security;
alter table app_users enable row level security;

drop policy if exists "open all products" on products;
drop policy if exists "open all activities" on activities;
drop policy if exists "open all users" on app_users;

create policy "open all products" on products for all using (true) with check (true);
create policy "open all activities" on activities for all using (true) with check (true);
create policy "open all users" on app_users for all using (true) with check (true);

-- ===== REALTIME =====
alter publication supabase_realtime add table products;
alter publication supabase_realtime add table activities;
alter publication supabase_realtime add table app_users;

-- ===== SEED USERS (rediger gerne navnene) =====
insert into app_users (name) values
  ('Jette'), ('Kirsten'), ('Thomas'), ('Ramo'), ('Lars'), ('Medin')
on conflict (name) do nothing;
3 Indsæt projekt-URL og anon-nøgle

På Supabase → Project Settings → Data API. Kopiér Project URL og anon / public nøglen. (Anon-nøglen er sikker at eksponere — RLS beskytter dataene.)

Allerede konfigureret? Genstart appen — eller ryd localStorage hvis noget er gået galt.
